Piece Rendering ↔ Placement: One Shared Anchor
The same offsets (dr, dc) define both what the agent sees and where the piece lands. Anchor = bounding-box top-left = cell (0,0) (example piece: J‑0).
What the agent SEES
pieces[i] — 5×5 grid
shape_to_grid(): grid[dr][dc] = 1
action (row=2, col=3)

board[row+dr][col+dc]=1
→
same (dr,dc)
just shifted by the anchor
Where it is PLACED
board — 8×8 grid
step(): writes (row+dr, col+dc)
piece cell (number = same cell on both grids) anchor (0,0) / (row,col) — may be empty; padding always sits bottom-right
Why it matters: the relative shape the agent sees in the 5×5 patch equals the relative footprint it places on the board — no hidden coordinate conversion to learn.
